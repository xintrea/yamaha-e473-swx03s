## Введение

Этот репозитарий создан для исследования возможности изменить
и доработать музыкальные функции синтезатора Yamaha PSR-E473.

Здесь собраны три кусочка паззла:

  * Терминал доступа к инженерной консоли синтезатора Yamaha PSR-E473
  * Дампер заданного диапазона адресов в файл
  * Готовые дампы памяти

### Терминал доступа к инженерной консоли синтезатора Yamaha PSR-E473

Утилита `shell.py` запускает консоль. При первом запуске консоли
с момента включения синтезатора, необходимо ввести символы:
```
login
#0000
```
В ответ покажется приглашение ввода в виде символа ">".
Для начала можно ввести команды help и info.

Описание команд находится здесь:

[Описание команд встроенного шелла в синтезаторах Yamaha линейки PSS/PSR](https://webhamster.ru/mytetrashare/index/mtb0/1742993139bs4irilhoq)

### Дампер заданного диапазона адресов в файл

Для сохранения данных из заданного диапазона адресов в файл,
используется скрипт `dump.py`. Перед запуском следует
указать необходимый диапазон в переменных:
```
addr_from='0B000000' # HEX-адрес без префикса 0x
addr_to  ='0C000100'
```
**Примечание**: Так как дампер состоит из двух потоков - поток
отправки управляющих команд и поток получения
символов из консоли, то на последнем блоке
из 256 байтов, поток отправки управляющих команд
будет завершен, а поток получения символов будет 
еще работать, что вызовет ошибку. Поэтому чтобы
в файл попали все нужные байты, надо конечный адрес указывать
на `0x100` больше, чем требуется.

### Готовые дампы памяти

В файле `data.7z` лежат дампы памяти следующих диапазонов адресов:
```
00000000 00003FFF
01000000 01017FFF
08000000 08FFFFFF
09000000 09FFFFFF
0A000000 0AFFFFFF
```
Для открытия данного архива следует внимательно прочитать
файл `data.txt`.

Это не полные дампы всей памяти (одни только эти дампы снимались
более двух недель). Предположительно, в оставшемся диапазоне
лежат только оцифровки звуков, стили и прочие данные, и они не
представляет исследовательского интереса.

## Предмет исследования - чип Yamaha SWX03S для синтезатора PSR-E473

В данный момент необходимо понять, что представляет из себя
микросхема **Yamaha SWX03S**. Самое главное, надо выяснить
какая система команд у этой микросхемы.

В более старом синтезаторе **PSR-E433** использовался чип 
**Yamaha SWL01U**, представляющий из себя ARM-процессор со
стандартной системой команд. Однако для чипа **SWX03S**
выяснить систему команд пока не удалось.

Предположительно, в SWX03S используется архитектура
**SuperH SH-2 RISC**. В следующий статье приведен
начальный анализ чипсета:

[Информация о работе с процессором SH-2 RISC (SuperH), предположительно используемом в Yamaha PSR-E473](https://webhamster.ru/mytetrashare/index/mtb0/1743666781xdns9kbonf)

Так же имеется еще одна статья, в которой анализаируется дамп:

(Попытка понять внутреннее устройство и схемотехнику синтезатора Yamaha PSR-E473)[https://webhamster.ru/mytetrashare/index/mtb0/17434285344rs2rjxa6u]

Автор пробовал анализировать дампы через утилиты:

  * binwalk
  * sh-elf-objdump
  * arm-none-eabi-objdump
  * Ghidra v. 11.3.1

Ни одна из утилит не дает ответа на вопрос, какая 
используется архитектура. Вроде бинарный код частично
похож на SH-2, SH-2A, SH-4. Но не получилось найти 
блока кода хотя бы из десятков байт, в котором бы 
не было "сбоя" на неизвестную инструкцию 
(где дизассемблер показывает `.word 0xABCD` 
вместо инструкции).

## Организация памяти

Так же надо понять, что находится в начальных
адресах памяти. И в каком формате - BE или LE.
Похоже, что там таблица веркторов прерываний,
но непонятно что она из себя представляет:
то ли это адреса (но почему они идут с периодом
в 6 байт а не 4), то ли это команды переходов,
но они либо нормально не дезассемблируются,
либо представляют собой достаточно бессмысленные
команды (а может в них таки есть логика?).
